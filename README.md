# 🤖 Jarvis Voice Assistant

A Python-based voice assistant inspired by Jarvis from Iron Man.

## ✨ Features
- Wake word activation ("Jarvis")
- Voice command recognition
- Opens apps like Spotify and Firefox
- Opens websites like YouTube and Google
- Tells time and date
- Voice responses
- Modular project structure
- GitHub version controlled

## 🛠️ Libraries Used
- speech_recognition
- pyttsx3
- datetime
- os
- random

## 🚀 Run the Assistant

```bash
python3 main.py
